# Week 1 – Custom AI Chatbot with Memory

## Internship
Generative AI Internship – DecodeLabs

## Project Overview
The objective of this project is to build a conversational AI chatbot that remembers previous user messages during an active conversation.

## Objectives
- Integrate an AI language model using an API.
- Maintain conversation history in an in-memory list.
- Send previous messages to the AI to preserve context.
- Store each AI response in the conversation history.
- Validate user inputs and handle API errors.

## Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
